# 하린문화예술 웹사이트

하린문화예술 공식 반응형 멀티페이지 웹사이트의 GitHub·Vercel 배포용 소스입니다.

## 로컬 실행

```bash
pnpm install
pnpm dev
```

## Vercel 배포

1. 이 폴더의 파일을 GitHub 저장소 최상위에 업로드합니다.
2. Vercel에서 **Add New → Project**를 선택합니다.
3. GitHub 저장소를 연결하면 Next.js 프로젝트로 자동 인식됩니다.
4. 별도 환경변수 없이 **Deploy**를 누릅니다.

문의 폼은 현재 화면 구성 단계이며, 실제 이메일 전송을 사용하려면 별도 API 연동이 필요합니다.
